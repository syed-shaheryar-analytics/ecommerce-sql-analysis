\# E-commerce SQL Revenue Analysis



\## Objective

Analyze transactional e-commerce data using SQL to extract revenue insights and business metrics.



\## Dataset Structure

Tables used:

\- users

\- orders

\- order\_items

\- products



\## Skills Demonstrated

\- Multi-table JOIN

\- GROUP BY

\- ORDER BY

\- LIMIT

\- Aggregate functions (SUM, AVG)

\- Subqueries



\## Business Questions Answered

\- What is total revenue?

\- What are monthly revenue trends?

\- What are the top 5 revenue-generating products?

\- Which cities generate the highest revenue?

\- What is the average order value?



\## Tools Used

SQLite (DB Browser)
